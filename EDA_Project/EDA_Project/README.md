# Exploratory Data Analysis (EDA) Project

A complete Exploratory Data Analysis project using the Breast Cancer dataset from scikit-learn.

## Objectives
- Generate statistical summaries
- Check missing values and duplicates
- Analyze feature distributions
- Identify correlations
- Create visualizations
- Generate structured insights

## Project Structure
```
EDA_Project/
├── README.md
├── requirements.txt
├── .gitignore
├── src/
│   └── eda_analysis.py
└── results/
    └── Generated automatically after running
```

## Installation
```bash
pip install -r requirements.txt
```

## Run
```bash
python src/eda_analysis.py
```

## Generated Results
- dataset_summary.csv
- descriptive_statistics.csv
- class_distribution.png
- correlation_heatmap.png
- feature_distributions.png
- pairplot.png
- insights_report.txt

## Expected Outcome
This project develops analytical thinking and data exploration skills by identifying patterns, distributions, correlations and important influencing factors.
